# Configuration d'une copropriété

## Où trouver cet écran ?

Fiche `Copropriété` > `Configuration`

## À quoi sert cet écran ?

La vue `Configuration` regroupe les paramètres juridiques, comptables et opérationnels propres à la copropriété.

Elle sert à préparer les éléments utilisés ensuite par la comptabilité, les répartitions, les documents et les envois.

## Sections visibles

La fiche peut contenir notamment :

* `Contrats de gestion`
* `Langues`
* `Syndic/agence actuel`
* `Affectations des rôles`
* `Séquences`
* `Paramètres`

## Raccourcis disponibles

Depuis cette vue, l'utilisateur peut accéder à :

* `Quotes-parts légales`
* `Clés de répartition`
* `Plan comptable`
* `Journaux comptables`
* `Comptes bancaires`

## Points à vérifier

Avant de démarrer les opérations courantes, vérifier au minimum :

* les langues utilisées ;
* les comptes bancaires ;
* les clés de répartition ;
* le plan comptable ;
* les journaux comptables ;
* les rôles et personnes en charge.
