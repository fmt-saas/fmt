# Documents d'une copropriété

## Où trouver cet écran ?

Fiche `Copropriété` > `Documents`

## À quoi sert cet écran ?

La vue `Documents` permet de retrouver les fichiers liés à la copropriété : factures, extraits bancaires, procès-verbaux, pièces jointes, courriers et documents importés.

## Vue liste

La liste `Documents` affiche les documents disponibles.

Elle permet d'importer un document, de l'ouvrir et de consulter ses informations principales.

## Fiche Document

La fiche `Document` permet de consulter :

* le fichier source ;
* les métadonnées ;
* la catégorie ;
* les étiquettes ;
* la visibilité ;
* l'analyse du document lorsqu'elle existe.

## Actions principales

* `Importer un document`
* `Lancer le traitement`
* `Afficher le document`
* `Métadonnées`

## Visibilité

La visibilité indique à quel périmètre le document est rattaché :

* `Copropriété`
* `Dossier de propriété`
* `Propriétaire`
* `Fournisseur`
* `Agence`
