# Vue Comptabilité

## Où trouver cet écran ?

Fiche `Copropriété` > `Comptabilité`

## À quoi sert cet écran ?

La vue `Comptabilité` regroupe les accès nécessaires au suivi financier de la copropriété.

Elle sert de tableau d'orientation pour passer rapidement d'une opération comptable à une autre.

## Raccourcis disponibles

La vue peut donner accès à :

* `Exercices comptables`
* `Fonds`
* `Budget`
* `Décomptes de charges`
* `Écritures comptables`
* `Opérations diverses`
* `États comptables`
* `Appels de fonds`
* `Factures d'achat`
* `Relevés bancaires`
* `Transferts d'argent`
* `Remboursements`
* `Encaissements`

## Parcours fréquents

Pour traiter une facture fournisseur : ouvrir `Factures d'achat`.

Pour demander des provisions aux copropriétaires : ouvrir `Appels de fonds`.

Pour clôturer une période et répartir les charges : ouvrir `Décomptes de charges`.

Pour traiter les mouvements bancaires : ouvrir `Relevés bancaires`.

Pour consulter les rapports : ouvrir `États comptables`.
