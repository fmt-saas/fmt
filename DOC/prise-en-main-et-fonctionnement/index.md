# Prise en main

Cette section s'adresse aux utilisateurs finaux : syndic, gestionnaire, comptable ou employé d'agence.

L'objectif est d'expliquer le logiciel à partir de ce qui est visible à l'écran : menus, listes, fiches, sections et boutons d'action.

## Comment lire cette documentation

Chaque page suit le même principe :

1. où trouver l'écran ;
2. à quoi il sert ;
3. ce que l'on voit dans la liste ou la fiche ;
4. quelles actions sont disponibles ;
5. dans quel ordre les utiliser.

Les libellés utilisés sont ceux de l'interface en français : `Copropriété`, `Dossier de propriété`, `Lots privatifs`, `Exercices comptables`, `Factures d'achat`, `Appels de fonds`, `Décomptes de charges`, `Relevés bancaires`, `Documents` et `Assemblées`.

## Parcours conseillés

Pour démarrer :

1. Lire les concepts de base.
2. Comprendre comment choisir une copropriété.
3. Ouvrir une fiche copropriété.
4. Consulter les pages métier selon le travail à faire : comptabilité, documents, assemblées, lots et propriétaires.

Pour comprendre le lien entre les montants attendus, les mouvements bancaires et les écritures comptables, consulter [Comprendre le rapprochement des paiements et le lettrage](comptabilite/rapprochement-paiements-et-lettrage.md).

Pour comprendre comment l'application reçoit des documents par e-mail et envoie les communications produites par les processus de gestion, consulter [Comprendre les boîtes mail](communication/boites-mail.md).
