# Consulter une liste

## À quoi sert une liste ?

Une liste présente plusieurs éléments d'un même type : copropriétés, lots, dossiers de propriété, factures, appels de fonds, décomptes, relevés bancaires ou assemblées.

Elle sert à rechercher, filtrer, comparer et ouvrir une fiche.

## Éléments visibles

Selon la liste, on peut retrouver :

* des colonnes de synthèse ;
* un statut ;
* des montants ;
* une date ;
* une copropriété ;
* un propriétaire ou fournisseur ;
* des actions disponibles dans l'en-tête.

## Utilisations courantes

Depuis une liste, l'utilisateur peut généralement :

* rechercher un élément ;
* filtrer les résultats ;
* trier par colonne ;
* ouvrir une fiche ;
* lancer une action globale lorsqu'un bouton est disponible.

## Exemples

* `Liste des copropriétés` : choisir l'immeuble sur lequel travailler.
* `Dossiers de propriété` : retrouver un copropriétaire et ses lots.
* `Factures (traitement)` : suivre les factures encore à compléter, valider ou intégrer.
* `Relevés bancaires` : identifier les extraits à rapprocher ou comptabiliser.
* `Assemblées` : consulter les assemblées planifiées et leur statut.
