# Modifier une fiche

## Principe général

Une fiche peut être modifiée tant que son statut et les règles métier l'autorisent.

Certains éléments deviennent verrouillés après validation, intégration ou clôture. C'est normal : cela protège l'historique comptable, les documents envoyés et les opérations déjà traitées.

## Avant de modifier

Avant de changer une information, vérifier :

* que vous êtes sur la bonne copropriété ;
* que la fiche ouverte correspond bien à l'élément à modifier ;
* que le statut permet encore la modification ;
* que le changement ne concerne pas une période déjà clôturée.

## Champs fréquents

Selon la fiche, les champs peuvent concerner :

* des informations générales ;
* une date ;
* un compte bancaire ;
* un fournisseur ;
* une période comptable ;
* une clé de répartition ;
* un document source ;
* des préférences de communication.

## Actions irréversibles ou sensibles

Certaines actions doivent être utilisées avec prudence :

* `Valider`
* `Activer`
* `Intégrer`
* `Annuler`
* `Cloturer`
* `Déverrouiller`

Ces actions peuvent générer des écritures comptables, envoyer des documents, verrouiller une période ou modifier le statut de plusieurs éléments liés.

## Bonne pratique

Lorsque l'action concerne la comptabilité ou l'envoi de documents, relire les informations principales avant de cliquer : période, montants, destinataires, compte bancaire et statut.
