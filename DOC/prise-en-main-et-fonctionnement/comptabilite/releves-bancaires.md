# Relevés bancaires

## Où trouver cet écran ?

Fiche `Copropriété` > `Comptabilité` > `Relevés bancaires`

## À quoi sert cet écran ?

La vue `Relevés bancaires` permet de traiter les extraits bancaires d'une copropriété, de rapprocher les transactions et d'intégrer les mouvements en comptabilité.

## Vue liste

La liste `Relevés bancaires` affiche les extraits importés ou encodés.

Une action `Importer` permet d'importer un relevé bancaire.

Statuts visibles :

* `À traiter`
* `Comptabilisé`
* `Annulé`

## Fiche Relevé bancaire

La fiche contient notamment :

* `Détails`
* `Lignes de transactions`

Champs importants :

* `Compte bancaire`
* `Date du relevé`
* `Numéro d'extrait`
* `Date d'ouverture`
* `Date de clôture`
* `Solde d'ouverture`
* `Solde de clôture`
* `Transactions`
* `Rapproché`
* `Équilibré`
* `Écritures comptables`

## Actions principales

* `Importer`
* `Rapprocher`
* `Intégrer`

## Parcours conseillé

1. Importer le relevé bancaire.
2. Vérifier le compte bancaire, les dates et les soldes.
3. Contrôler les lignes de transactions.
4. Cliquer sur `Rapprocher` pour tenter le rapprochement automatique.
5. Corriger les lignes qui restent à traiter.
6. Cliquer sur `Intégrer` lorsque le relevé est équilibré et prêt.
